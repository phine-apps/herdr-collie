# Herdr Collie

Herdr Collie is a VS Code extension designed to seamlessly integrate VS Code with the powerful AI agent platform **Herdr**.
Send the exact context you are looking at in your editor (code, errors, Git diffs, reviews, test failures, and more) to Herdr agents with a single click or keyboard shortcut, supercharging your AI-driven development workflow.

---

## 🚀 Key Features

### 1. Smart Swarm & Git Worktree Launcher
Parallelize AI agent tasks effortlessly without touching your main working directory:
- **Launch Agent in Git Worktree** (`Ctrl+Alt+H L`): Creates an isolated Git worktree on a new/existing branch, provisions a Herdr workspace, launches the specified AI agent (`claude`, `agy`, `cursor-agent`, `copilot`, or custom), and dispatches the task prompt in one seamless flow.
- **Worktree Sidebar Integration**: Worktrees are automatically badged with their branch name in the Workspaces view with a Git branch icon and quick inline actions to merge (`$(git-merge)`) or delete (`$(trash)`).
- **Merge & Cleanup**: Merge changes back to your active branch with one click upon task completion.

### 2. Agent Attention HUD & Quick-Action Notifications
Keep full situational awareness across all parallel agents with zero context switching:
- **Status Bar Live HUD**: Real-time summary on the bottom status bar:
  - `$(sync~spin) N Working`: Indicates active background processing.
  - `$(alert) N Waiting`: Highlights agents requiring user approval or confirmation.
  - `$(hubot) N Idle`: Clean idle overview.
- **Activity Bar Unread Badge**: The Herdr Collie activity bar icon displays a badge counter whenever one or more agents are waiting for confirmation.
- **Show Agent HUD** (`Ctrl+Alt+H H`): Opens an interactive QuickPick HUD menu to monitor all agents across sessions, inspect states, and approve pending confirmations in one place.
- **Interactive Approval Notifications**: When an agent transitions to waiting/blocked for confirmation (e.g. tool execution permission), a native notification pops up with interactive action buttons:
  - `[Approve (y)]`: Approves instantly without opening the terminal.
  - `[Deny (n)]`: Denies tool execution.
  - `[Quick Reply...]`: Opens an input box to send quick instructions.
  - `[Focus Terminal]`: Jumps straight to the agent's interactive terminal pane.

### 3. Integrated Visual Review & Diff-to-Prompt
Review code generated by AI agents directly inside VS Code before merging or committing:
- **Review Changes Sidebar Tree** (`herdr-collie.reviewChanges`): Lists all modified, added, and deleted files in the active workspace.
- **Single-Click Diff Editor**: Click any modified file in the Review Changes tree to open a native side-by-side diff (`HEAD ↔ Working Tree`).
- **Inline Review Comments** (`vscode.comments`): Add inline review comments directly on any line of code in the diff or editor (`Ctrl+Alt+H C`).
- **Automated Checkpoints & One-Click Rollback**: Automatically saves working tree checkpoints prior to reviewing. Roll back changes instantly (`$(history)`) if the agent took the wrong direction.
- **Diff-to-Prompt Feedback Dispatch** (`Ctrl+Alt+H R`): Packages all file diffs and inline review comments into a structured prompt and dispatches it directly to the agent to request revisions.

### 4. Micro-Task CodeLens & Quick-Fix
Delegate targeted tasks to AI agents with zero prompt engineering:
- **Diagnostic Quick-Fix (`Cmd+.` / `Ctrl+.`)**: When compiler errors or linter warnings appear, open the VS Code Quick-Fix lightbulb menu and select `🛠️ Delegate Fix to Herdr Agent` to send the exact error, file location, and relevant code chunk to an idle agent.
- **Test-Runner CodeLens**: Displays inline action links directly above test suites and test cases (`describe` / `it` / `test`):
  - `▶ Fix Test with Herdr Agent`: Dispatches the test definition and failure context to an agent.
  - `🧪 Generate Edge Cases`: Prompts the agent to write boundary conditions and edge-case unit tests.
- **TODO Completion CodeLens**: Displays `▶ Complete TODO with Herdr Agent` above `// TODO:` or `// FIXME:` comments to auto-delegate pending tasks.
- **Smart Context Dispatch (`Ctrl+Alt+H Enter`)**: Press `Ctrl+Alt+H Enter` anywhere in an active file to automatically inspect cursor context (diagnostics, tests, or TODOs) and dispatch it to the nearest idle agent. If multiple agents are active, an idle-prioritized QuickPick lets you select the target agent.

### 5. High-Signal Context Bridge
Send rich development context to your AI agents immediately via shortcuts, context menu, or Command Palette:
- **Send Selection** (`Ctrl+Alt+H S`): Sends selected lines of code with filename, language, and line numbers.
- **Send Symbol Info (Hover)**: Sends full type definitions, function signatures, and JSDoc / hover details of the symbol under the cursor.
- **Send Errors/Warnings** (`Ctrl+Alt+H D`): Sends active file diagnostics.
- **Send Workspace Problems**: Sends project-wide errors and warnings in a single batch (ideal after refactoring).
- **Send Terminal Output / Error**: Sends recent output or selected text from the integrated terminal.

### 6. Git & SCM Integration
Deep integration with VS Code's Source Control (SCM) view:
- **Send Staged Changes**: Sends staged diffs (`git add`) for commit message generation or pre-commit reviews.
- **Send Working Tree Changes**: Sends unstaged working tree diffs.
- **Send Branch Context**: Sends the current branch name and commit history since branching off the base branch.

### 7. Herdr Sessions, Workspaces & Agents Management
Manage your Herdr environment directly from the **Herdr Sidebar Panel** (organized into **Sessions**, **Workspaces**, **Agents**, and **Review Changes** views) or via fast keyboard selectors:
- **Sessions View**: View active and background Herdr sessions, switch active views with a single click, create new sessions (`+`), or delete custom sessions (`$(trash)`).
- **Workspaces View**: Create, rename, delete, and focus Herdr workspaces, with instant Git Worktree integration.
- **Agents View**: Monitor live agents with status indicators (`🟢 Working`, `🟡 Waiting`, `⚪ Idle`, `🔴 Blocked`) and toggle sort order between **Grouped** (by workspace) and **Priority** (Attention Queue urgency) with one click (`$(list-ordered)`).
- **Optimized Terminal UI**: When launching Herdr inside VS Code's integrated terminal, the standard Herdr TUI sidebar is automatically hidden to avoid redundancy with VS Code's sidebar, maximizing terminal screen real estate.

### 8. Multi-Language Support (Internationalization)
Herdr Collie features native localization support across all views, menus, dialogs, and notifications:
- 🇺🇸 **English**
- 🇯🇵 **Japanese (日本語)**
- 🇨🇳 **Simplified Chinese (简体中文)**

Language packs seamlessly follow your VS Code display language setting.

## 🤖 Agent Integrations Setup

To enable Herdr Collie to automatically detect AI agents like Claude Code or Antigravity, send prompts directly (`agent prompt`), and monitor their live status (Working 🟢 / Waiting 🟡 / Idle ⚪), **the corresponding agent integrations must be installed in Herdr**.

Run the following commands in your terminal to enable integrations for the AI tools you use:

```bash
# Check current integration installation status
herdr integration status

# Install integrations for each AI agent
herdr integration install claude            # For Claude Code
herdr integration install antigravity-cli   # For Antigravity CLI (agy)
herdr integration install copilot          # For GitHub Copilot CLI
herdr integration install codex            # For Codex CLI
herdr integration install cursor           # For Cursor
```

> [!NOTE]
> Once installed, whenever the corresponding AI agent runs inside a pane, it will automatically appear in Collie's "Agents" view and be available as a context destination.

## ⚙️ Requirements & Configuration

- **Requirements**:
  - Visual Studio Code 1.90.0 or higher
  - Herdr CLI available in your system `PATH`
  - Git CLI installed (for Git Worktree and SCM integration)
  - Agent integration installed via `herdr integration install <target>`

- **Configuration Settings**:
  - `herdr-collie.sessionName` (default: `"vscode"`):
    Session name used when launching Herdr from VS Code's integrated terminal.
  - `herdr-collie.defaultAgentCommand` (default: `"claude"`):
    Default AI agent command used when launching agents in Git worktrees (`"claude"`, `"agy"`, `"cursor-agent"`, `"copilot"`, etc.).
  - `herdr-collie.worktreeLocation` (default: `"sibling"`):
    Directory layout for Git worktrees (`"sibling"` creates `../<repo>-<branch>`, `".worktrees"` creates inside repository).
  - `herdr-collie.agentSortOrder` (default: `"grouped"`):
    Default sort order in the Agents view (`"grouped"` or `"priority"`).
  - `herdr-collie.agentHUD.enableNotifications` (default: `true`):
    Enables native interactive notifications when an agent enters waiting/blocked state.
  - `herdr-collie.codeLens.enable` (default: `true`):
    Enables inline CodeLens action links for test runners and TODO items.
  - `herdr-collie.quickFix.enable` (default: `true`):
    Enables `🛠️ Delegate Fix to Herdr Agent` in VS Code's Quick-Fix lightbulb menu (`Cmd+.`).
  - `herdr-collie.hideHerdrSidebar` (default: `true`):
    Automatically hides Herdr's built-in TUI sidebar in the integrated terminal to maximize screen area.
